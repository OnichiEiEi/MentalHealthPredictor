# Mental Health Predictor API

A FastAPI-based API that predicts mental health scores based on user inputs such as screen time, sleep quality, stress level, sleep hours, and age.

---

## Features

- **Health Check**: Verify if the API is running.
- **Prediction Endpoint**: Submit user data and receive a predicted mental health score.
- **CORS Enabled**: Allows requests from any origin.
